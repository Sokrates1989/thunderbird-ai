# Security Policy

> [Deutsche Version](SECURITY.de.md)

## Supported versions

Security fixes are provided for the latest published release. Users should update through the newest GitHub or Thunderbird Add-ons release before reporting an issue.

## Reporting a vulnerability

Do not disclose exploitable vulnerabilities, API keys, email content, local paths, or profile data in a public issue. Send a minimal report to `thunderbird-ai@felicitas-wisdom.com` with the affected version, platform, impact, and reproduction steps using synthetic data.

The maintainer will acknowledge a usable report, investigate it, and coordinate a fix and disclosure timeline. No monetary bug bounty is currently offered.

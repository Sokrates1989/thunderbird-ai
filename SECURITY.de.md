# Sicherheitsrichtlinie

> [English version](SECURITY.md)

## Unterstützte Versionen

Sicherheitskorrekturen gelten für die neueste veröffentlichte Version. Vor einer
Meldung sollte über GitHub oder Thunderbird Add-ons aktualisiert werden.

## Schwachstelle melden

Ausnutzbare Schwachstellen, API-Schlüssel, Mailinhalte, lokale Pfade und
Profildaten nicht öffentlich melden. Eine minimale Meldung mit Version,
Plattform, Auswirkung und Reproduktionsschritten mit synthetischen Daten an
`thunderbird-ai@felicitas-wisdom.com` senden.

Der Maintainer bestätigt verwertbare Meldungen, untersucht sie und koordiniert
Korrektur und Offenlegung. Derzeit gibt es kein monetäres Bug-Bounty-Programm.

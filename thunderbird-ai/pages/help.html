Thunderbird AI Assistant – Hilfe

Öffnen Sie eine E-Mail und klicken Sie auf das Add-on-Symbol. Die Schnellaktionen analysieren ausschließlich die aktuell geöffnete Nachricht.

Einrichtung

  1. Öffnen Sie Einstellungen.
  2. Tragen Sie Ihren OpenAI API-Schlüssel ein.
  3. Wählen Sie Automatisch (empfohlen) und testen Sie die Verbindung.
  4. Speichern Sie die Einstellungen.

Datenschutz

Bei AI-Aktionen werden Betreff, Absender, Nachrichtentext und Anhangnamen direkt an die OpenAI API gesendet. „Ähnliche finden“ arbeitet ausschließlich lokal. Automatische Analyse ist standardmäßig deaktiviert.

Fehlersuche

Wenn eine Aktion fehlschlägt, prüfen Sie zuerst den API-Test. Bei nicht lesbarem Inhalt öffnen Sie die Nachricht vollständig und versuchen Sie es erneut.

Thunderbird AI Assistant – Help

Open an email and click the add-on icon. Quick actions analyze only the currently displayed message.

Setup

  1. Open Settings.
  2. Enter your OpenAI API key.
  3. Select Automatic (recommended) and test the connection.
  4. Save the settings.

Privacy

AI actions send the subject, sender, message text, and attachment names directly to the OpenAI API. “Find similar” runs locally. Automatic analysis is disabled by default.

Troubleshooting

If an action fails, run the API test first. If no readable content is found, fully open the message and try again.
